# fitEstimator

fits a deep learning estimator to data.

## Usage

``` r
fitEstimator(trainData, modelSettings, analysisId, analysisPath, ...)
```

## Arguments

- trainData:

  the data to use

- modelSettings:

  modelSettings object

- analysisId:

  Id of the analysis

- analysisPath:

  Path of the analysis

- ...:

  Extra inputs
